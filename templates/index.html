Who it is for

  • Australian tax residents investing on capital account — individuals and SMSF trustees holding shares and options through IBKR. Not for traders: if your trading is taxed on revenue account, these figures do not apply to you.
  • Parcels bought before 2023 are not supported yet. The bundled RBA rate table starts on {{ rba_first }}; a parcel acquired earlier stops the run.
  • Checked so far only against real statements from USD base-currency accounts. AUD base-currency accounts are untested — check the figures closely and report anything odd.
  • Not tax advice. A record-keeping and calculation working paper: have a registered tax agent review it before you lodge.

Your files

{% if hosted %}
  • Sent over HTTPS to this server and processed in memory. The CSVs you upload are never written to disk.
  • The report is kept for at most {{ ttl_minutes }} minutes. The workpaper CSV, PDF and ZIP are held in memory-backed storage so you can download them, then deleted automatically. Delete my results now removes them straight away.
  • No logging of file contents, no analytics, no tracking, no cookies. Your IP address is held in memory for up to an hour after your last report, for rate limiting only.
  • Rather not upload? It is open source (MIT): run it on your own machine — clone the repository, run the setup script, then python app.py. Nothing leaves your computer that way.
